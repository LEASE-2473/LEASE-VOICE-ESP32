# 电脑端后台屏幕播放

状态：2026-11-04，软件0.6.0，沿用现有M3.1固件，无需重新烧录。

## 使用

1. 在屏幕页选择素材加入播放列表，确认尺寸、方向、裁切及缩放。
2. 点击「开始后台播放」。这会保存当前播放列表与播放设置，以已保存的屏幕配置开始推送。
3. 可以离开或关闭控制页，电脑本地服务与隐藏播放器继续运行。再次进入屏幕页能看到后台累计帧数、当前素材和错误状态。
4. 「暂停后台」冻结动画并继续推送最后画面，避免固件断流清黑；「继续后台」「后台下一个」控制后台播放器。「停止设备画面」释放隐藏播放器并按流ID停止设备。

左侧「开始循环」和单个素材「预览」仍是本页预览，不代表已启动后台。测试色块用于现场调试，仍由本页推送，离页即停止；开始测试色块会先停止后台，二者不争抢设备流。

更改列表/缩放/背景等之后，请重新点击「开始后台播放」应用。修改屏幕方向/尺寸、设备地址或Token前请先停止；保存新的设备配置也会停止旧后台流。后台不跟随未保存的页面临时预览，不跟随桌宠动作。

## 运行条件与边界

- 使用宿主电脑已安装的Microsoft Edge，无需安装浏览器扩展；不下载浏览器。可用LEASE_VOICE_BROWSER_PATH或EDGE_PATH指定已有兼容浏览器的可执行文件。
- 插件包随附playwright-core（生产依赖），用无头模式解码，不打开可见浏览器窗口；不依赖开发依赖playwright。只在开始播放后启动一个独立播放器，停止/错误/宿主卸载时关闭。
- 播放必须保持电脑和本地软件运行。电脑休眠、网络断开或进程退出会中断；未实现Windows开机自启、系统服务或退出后继续运行。后台运行状态不写配置，重启软件后需再次点击开始。
- 当前网络/解码失败会显示错误并释放资源，检查网络后重新开始；尚未实现自动重连。保存的素材和设置保留。
- 本次完成的是动画后台播放，工作/空闲/完成素材分组与DSH事件自动切换尚未实现。完成提示/TTS仍沿用当前可见聊天会话的事件机制，不能将动画后台化视为后台语音通知已完成。

## 实现与资源

`core/screen-background.js`持有唯一后台运行实例、串行控制与状态；`core/screen-renderer.js`启动隐藏Edge，复用`client/screen-player.js`的播放/裁切/缩放，将canvas量化为RGB565BE。内部媒体请求仅允许已入库ID，通过浏览器私有路由读取，不开放新的HTTP端口，不加载外网网页，不把设备Token交给渲染器。

`extensions/display.js`继续负责设备鉴权、屏幕配置、流ID和序号、单帧背压及5秒网络请求超时。最多约5fps，完成上一帧确认后才生成/发送下一帧，无历史帧队列。设备照旧仅保留最新待显示帧、显示后释放，不存动画Flash；累计已接收帧数不是保存的图片数。

控制接口为宿主owner认证下的`GET/POST /api/lease-voice/screen-playback`；操作start/stop/pause/resume/next。打开页面只轮询状态，不会启动或接管播放器；页面pagehide不会停止后台。日常DSH尚未升级，本项目4318回环预览独立运行，不能对外开放。

## 验证

`npm.cmd test`包含无页面心跳的循环、背压、暂停/继续、停止释放、启动中取消、首帧及运行中断网、空列表与尺寸校验。

`npm.cmd run test:background`使用真实Edge和Node协议模拟器验证红色像素RGB565、实际控制页切换和关闭后继续推送、重新打开控制、暂停/继续/下一项、停止释放；本机有pet素材时另验证真实VP9多帧变化。模拟器不执行ESP32 C/SPI，实物及长期稳定结果另记根日志。
