# 电脑端屏幕播放与完成提示

状态：2026-11-04，项目电脑端0.6.0新增独立后台动画播放（沿用0.5.0本地语音库/缓存保存）；设备仍M3.1，既有现场色块/白框、横屏人物正立及pet动画确认保留。本机控制页可调0.5～3倍缩放。日常DSH仍0.2.0，未升级/重启。

## 已确定的职责

电脑管理素材、播放列表、动作选择、随机规则、画面适配与回复完成事件。pet、meme 只提供可选的文件来源，既不修改原插件，也不订阅或同步桌宠动作。小屏幕可以独立播放完全不同的内容。

ESP32只接收电脑已处理的画面、音频与控制指令，负责短缓存、屏幕/I2S驱动和状态反馈。动画和提示音不写Flash；提示音从电脑素材库读取或本地生成「叮」，通过已有PCM协议发送。固件不需要TTS、WebM/VP9播放器或pet/meme业务代码。

canvas预览目标12fps，推送最多约5fps（一次一帧，等待接收确认后继续）。此前1.8寸实物使用ST7735S128×160配置兼容，横屏逻辑160×128、swapXY/mirrorX/mirrorY均true、偏移0、bgr/invert false，用户确认颜色/边框/方向。0.6.0重载时原样保留用户最新已保存配置：swapXY/mirrorX true、mirrorY false、偏移0、bgr/invert false、cover/zoom1.1、黑底和8项列表；不自动恢复历史基线。实际浏览器两段120秒动画约4.8帧/秒、无显示错误，仍非长期保证。未读取芯片ID，不认定精确器件型号；其他屏幕规格仅实现/模拟验证。

## 界面与素材

入口是 DSH「设置 → 语音扩展 → 管理屏幕播放」，也可从现有设置页顶部的「屏幕播放」进入。仍保留原来两个 DSH 设置插槽。

- 自动发现当前插件可解析的 `dsh-pet` / `@linxin666/dsh-pet` 的 `assets/webm`，`dsh-meme/memes` 和 DSH_HOME 下的 `meme-packs`；解析基点包括当前插件、DSH_HOME 和其 profiles/web。未安装可选插件不阻断本地播放。
- 可在目录设置中为 pet、meme 分别填写电脑上的绝对目录；留空恢复自动发现。目录是 DSH 宿主所在电脑的路径，远程浏览器可通过文件选择器导入自己的文件。
- 支持 PNG、JPEG、GIF、WebP、WebM、MP4；检查扩展名、文件头与大小，实际解码能力取决于浏览器。未实现格式转码或坏媒体修复；错误文件显示失败，可手动切到下一项。
- 原插件目录只读；本地导入文件独立保存，可以删除。单文件 ≤32MiB；本地库 ≤256MiB/500 项；列表 ≤300 项；扫描深度 ≤5，每来源最多遍历 5000 项，总扫描库最多 2000 项。
- 列表支持添加、移出、上下移动、清空、顺序/随机循环（多项不紧邻重复）。图片/GIF 停留 1～120 秒；视频静音完整播放后切换；支持完整显示/裁切铺满和背景色。
- 0.4.1增加0.5～3倍缩放，默认1，与contain/cover叠加，保存后重新开始循环生效。当前实物cover/zoom1获用户认可；想放大可小幅试1.1，但可能裁掉动作边缘，不能承诺放大同时保留全部内容。
- 普通预览随页面关闭；「开始后台播放」由电脑隐藏播放器执行，离开/关闭页面仍继续，可返回页面暂停/继续/下一项/停止。开始后台时保存并应用当前列表和播放设置，后续更改需重新开始。详见[后台播放](BACKGROUND_SCREEN.md)。

## 实体屏幕推送（需M3固件）

在原扩展页保存设备地址/Token后，进入屏幕页检查接收能力。旧M2固件明确提示需要M3，不发送配置或帧。先选1.8寸8针候选配置，保存屏幕配置并使模拟尺寸一致，再主动点击「推送测试色块」或「开始后台播放」。不会因页面加载或保存配置而启用屏幕。

测试色块由电脑绘制红绿蓝白黑，用于现场校验颜色、方向及偏移；可调整xGap/yGap、BGR、反色、镜像及横竖交换。修改硬件配置前先停止设备画面。前端把canvas不透明画面量化RGB565BE，经owner认证宿主转发；设备Token不进入浏览器。

每帧最多153600字节、只保留最新待显示帧，不存Flash。queued仅表示接收，drawn仅表示SPI事务结束，均不证明用户看到了正确画面。后台暂停时继续发送最后一帧；只有显式停止/软件退出或错误才释放后台流，关闭控制页不停止后台。测试色块随页面关闭尽力停止。异常断流由设备5秒清黑并释放流。迟到stop不能清掉新流。

协议见[画面传输v1](../shared/protocol/device-display-v1.md)，引脚及现场证据见[固件M3说明](../firmware/esp32-s3/docs/M3_DISPLAY.md)。本机项目控制页已保存真实设备凭据及方向，仍只监听127.0.0.1；不要把该无DSH登录保护的开发服务开放到网络。独立tools/data/screen-acceptance用于硬件测试，不复制provider凭据。

## 完成提示

`config.json` 的 completion 默认关闭，可选浏览器或 ESP32、0～100 强度，以及叮声、随机勾选语音或固定第一段勾选语音。6段用户素材已导入本机控制页；随机不紧邻重复。统一24kHz/16bit单声道，浏览器用WAV，设备用原始PCM；已有素材播放无需provider。设备还会叠加自身音量。导入/试听/下载/删除和保存已有TTS结果见[本地语音素材与保存](COMPLETION_SOUNDS.md)。

自动提示复用已有主会话最终回复筛选和当前可见窗口租约，独立于手动/自动朗读模式。开启后只消费新的成功回复事件，不补历史，不提示工具过程、失败/中断、子会话或后台来源；多窗口按消息身份去重。浏览器先点击聊天顶部「启用声音」。

同一条新回复先排完成提示，播完再合成/朗读正文；完成提示优先于尚未开始的正文队列，不硬打断当前声音。排队合法窗口15分钟；关闭提示或停止会清理对应任务。不同会话/试听客户端之间不做全局混音，设备被其他任务占用时明确报错。当前仍依赖可见主会话页面，没有宿主常驻通知服务；工作/空闲/完成动画分组及生命周期切换尚未实现。

## 数据、接口与边界

- `host/routes.js`：所有页面、媒体内容、上传与设置走已有 owner 认证的 `/api/lease-voice/*`，不另开生产端口。
- `core/media-library.js`：在 `LEASE_VOICE_DATA_DIR`（默认插件 data）保存 `screen.json` 和 `media/`。独立于含凭据的 `config.json`，升级须保留整个 data 目录。
- 媒体只按扫描/导入生成的 ID 提供，不接受客户端任意文件路径；跳过符号链接，提供文件时再次验证目录边界、大小及文件头。视频支持单段 HTTP Range。删除只允许本插件导入的文件。
- `client/screen-player.js`负责浏览器解码/canvas；`client/frame-sender.js`负责RGB565编码、5fps节流、逐帧背压、停止/离页取消；`extensions/display.js`负责固件能力检查、初始化、单窗口所有权、注入Token、序号/尺寸校验及超时。`screen-control`/`screen-frame`由host认证，不是直接公开设备代理。
- `core/screen-background.js`、`core/screen-renderer.js`：宿主后台隐藏Edge复用播放逻辑，owner接口screen-playback，无新HTTP端口；逐帧确认、错误/停止释放。
- `core/chime.js`、`core/tasks.js`：提示音复用任务、取消、缓存与设备 PCM 播放，不修改现有固件协议。
- 不将第三方原始素材打入插件包；本机读取和未来对外分发的授权边界分开，公开分发前应逐项核对素材许可和来源。

## 本地运行与验收

在 `software/dsh-voice` 运行：

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run check
npm.cmd run test:browser
npm.cmd run test:screen
npm.cmd run test:background
```

电脑隔离预览：

```powershell
$env:DSH_HOME = 'D:/LEASE AI Software/Deepseek Harness'
$env:LEASE_VOICE_PREVIEW_DATA_DIR = Join-Path (Get-Location) 'data/screen-preview'
npm.cmd run preview
```

访问 `http://127.0.0.1:4318/api/lease-voice/screen`。只监听回环，无 DSH 登录保护，使用独立预览数据；不填真实 provider 凭据。未指定预览数据目录时使用临时目录。预览没有真实 DSH 回复事件，自动完成提示须通过真实 Session/Connection 隔离测试及 React 宿主模拟验证，不能从此页面假称日常 DSH 已通知成功。

`test:screen`验证真实浏览器画面像素、播放/暂停/切换、视频循环、列表持久化、提示音、错误文件及移动布局，并验证色块RGB565经真实HTTP送到Node协议模拟器、单帧背压及停止；模拟器不执行ESP32 C/SPI。本机存在dsh-pet时另验证实际WebM/VP9解码，不把这段素材发布。截图输出到忽略的artifacts。
