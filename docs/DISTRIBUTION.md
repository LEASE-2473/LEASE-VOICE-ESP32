# 公开发行范围与安装（0.7.0）

不能只提交 software 和 firmware：还应提交 shared 协议、tools 配网/烧录脚本、docs、根 README 和连续性文档。hardware 厂商资料、用户提示音原件、data/密钥、node_modules、调试日志、artifacts 不公开。发布前确认源码许可证和第三方资源再分发许可；当前未指定开源许可证，不等同于授予开源许可。

## 不购买 ESP32

安装插件即可使用浏览器朗读及完成提示；不需要串口、固件或其他桌宠插件。配置页填写自己的 TTS 凭据，保存设置后可另存最多50份命名配置（含供应商与音色）；凭据只存宿主、不回显。语音页设置手动/自动、完成提示及导入个性化 MP3/WAV。默认手动、提示关闭，内置合成叮声无需外部素材。首次自动播放先在聊天顶部启用声音。先提示、后自动正文朗读。

## 可选 ESP32

设备页顶部选择输出。只有认证连接检查成功、支持 audio-pcm16 的设备才出现 ESP32 选项；无连接仅浏览器。下方 details 默认折叠；展开ESP32配置后始终显示「画面推送」入口，未连接也能进入管理素材/预览；状态会区分未连接、仅音频与支持屏幕接收，实体推送仍需M3能力校验并手动发起。选择输出后点击保存，朗读与完成提示共同切换。连接只代表检查时在线，不保证之后持续可用，断网后需重新检查。

firmware/esp32-s3/release 固定提供 M3.1 三个 bin 与原始 manifest（保留构建时 hardware_tested:false；历史实物验收见上下文）。仅支持文档中配套 ESP32-S3 N16R8/16MB Flash 板，不是任意 ESP32 通用固件。Windows 双击 tools/flash-and-setup.cmd，或安装包中 device/flash-and-setup.cmd；要求已装 Python/esptool==4.8.1 和 USB 驱动。先检查哈希、显式确认型号/覆盖风险，再烧录并打开配网窗。可传 -Python 指定环境、-Port COM3；-Check 只校验不访问串口。不会下载 SDK，不会自动备份，不会整片擦除；新分区不兼容旧设备时也不保证保留数据。配网完成后把地址/Token填入设备页，电脑与设备需网络互通。屏幕仍须明确配置启用。

## 本地安装包

在 software/dsh-voice 执行 npm ci，再 npm pack --pack-destination artifacts。prepack 自动构建和语法检查；files 白名单包含程序、界面、内置合成提示音代码、device 固件和配置工具，生产依赖 ws/playwright-core 随包分发。没有用户私有提示音或凭据。后台画面需要本机可用 Edge，但浏览器语音无需该功能。

在 DSH 的插件/软件包管理入口选择生成的 dsh-lease-voice-0.7.0.tgz 本地安装并按宿主提示重载；不要解压覆盖整个 DSH 目录。既有安装先备份插件 data，并确认重新安装使用的是新 tgz，而非 profile 中旧包来源。本轮未在生产宿主执行安装，不保证不同宿主版本管理入口一致。
## Windows USB 工具与配对文件

Windows 窗体只在电脑上运行，不编译进固件；串口仍使用 wifi-set/status JSON 协议。配网窗自动列出串口并可刷新或手填；烧录启动器选择的 -Port 会传入配网窗。USB 中断、超时、设备确认及联网 IP 分别反馈；检查模式不打开串口。

联网后点击「导出配对文件」，选择安全的本地目录。文件仅含 name、endpoint、token，不含 Wi-Fi 密码或串口号。设备页展开 ESP32 配置后导入，核对地址、保存设备，再点击连接检查。导入不会自动访问文件中的地址。文件为明文敏感凭据，不应放进源码目录、Git、日志、聊天或发行包；*.pairing.json 已忽略，但改名仍需自己保护。工具不再自动把凭据写到项目目录。

烧录依赖 Windows PowerShell/WinForms、Python、esptool 4.8.1 和串口驱动；不是零依赖一键安装。普通浏览器用户完全不需要这些工具。发行包 device/ 中只包含脚本及固定固件镜像，禁止放配对文件或运行数据。
